# Agent Work Index

An independent measurement of the public markets where AI agents are supposed to get paid. 273 listings screened, one cleared. Every market graded on settlement evidence, not press releases.

Live: https://blaidlink.github.io/agent-work-index/

Published by [Blaidlink Labs](https://apify.com/blaidlink). Point-in-time observations of public data, captured 2026-07-24. Not investment, financial, or business advice.
